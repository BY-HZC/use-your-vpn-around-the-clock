# Repository guidance for Codex and other coding agents

This is a public configuration project. Treat all existing code and config as untrusted until inspected.

- The canonical routing policy is `config/routing.json`; `dist/` is generated by `python3 scripts/generate.py`.
- Preserve behavior: mainland-China services and CN IPs DIRECT, explicitly international services PROXY, unmatched traffic PROXY.
- Do not embed any personal proxy nodes, subscriptions, credentials, access tokens, private IPs, or user-specific logs.
- `dist/mihomo.yaml` and `dist/android-flclash-template.yaml` MUST keep the example.invalid placeholder, never a real subscription URL.
- FlClash override replaces subscription routing rules; keep this caveat documented.
- Before committing: `python3 scripts/generate.py --check` and `python3 -m unittest discover -s tests -v`.
- Review all staged files for secrets, especially dotfiles and generated output.
- Do not force-push, overwrite an existing remote, or publish without explicit user instruction.
- If GitHub authentication fails or rate limits occur, stop and ask the user to sign in normally. Never bypass verification.
- Describe this release as Beta/Preview; static tests do not prove Android device compatibility.
